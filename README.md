# Jazzy – Jewelry Store UI Demo

A responsive front-end e-commerce product layout for a jewelry store, built using HTML and CSS with Grid and Flexbox.

Live Demo: https://someshwar4898.github.io/jewelry-store-demo/

## Features
- Responsive product grid layout
- CSS Grid and Flexbox for alignment and spacing
- Hover effects for product cards
- Clean UI structure suitable for e-commerce websites

## Tech Stack
- HTML5
- CSS3 (Grid, Flexbox)
